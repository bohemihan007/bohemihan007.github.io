개인정보처리방침

오라클 · 2026년 9월 2일 시행

오라클은 한석진 개인이 자기 업무를 처리하려고 만들어 혼자 쓰는 도구입니다. 사용자는 만든 사람 한 명이며, 다른 사람에게 배포하지 않습니다.

1. 다루는 정보

  • 구글 주소록의 연락처 — 이름, 전화번호, 이메일, 소속, 직함, 주소, 메모
  • 인증 정보 — 구글이 발급한 액세스·갱신 토큰

2. 쓰는 목적

사용자 본인의 구글 주소록에 연락처를 추가하고, 같은 사람이 이미 있는지 확인하기 위해서만 씁니다. 그 밖의 목적으로 쓰지 않습니다.

3. 권한 범위

https://www.googleapis.com/auth/contacts 하나만 요청합니다. 메일, 드라이브, 사진, 캘린더에는 접근하지 않습니다.

4. 보관과 전송

  • 인증 토큰은 사용자 본인의 컴퓨터에만 저장됩니다. 외부 서버로 보내지 않습니다
  • 연락처 정보는 구글과 사용자의 컴퓨터 사이에서만 오갑니다
  • 제3자에게 제공하거나 판매하지 않으며, 광고·분석에 쓰지 않습니다
  • 별도의 서버나 데이터베이스를 운영하지 않습니다

5. 권한 철회와 삭제

구글 계정의 앱 권한 관리에서 언제든지 이 앱의 권한을 지울 수 있습니다. 지우는 즉시 토큰이 무효가 되고 더 이상 주소록에 접근하지 못합니다. 사용자 컴퓨터에 저장된 토큰 파일을 지우면 그 사본도 사라집니다.

6. 구글 API 서비스 사용자 데이터 정책

오라클이 구글 API 로 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy를 따르며, 여기에는 제한적 사용(Limited Use) 요건이 포함됩니다.

7. 변경
